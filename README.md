# Eli Ecton — Cybersecurity Portfolio

Associate of Applied Science in Cybersecurity, Northern Virginia Community College (NVCC)

This repo holds write-ups from hands-on coursework projects covering vulnerability assessment, network security, and digital forensics. Each project folder has a README with an overview, tools used, process, and key findings, plus the full report.

## Projects

- **[Hackazon Vulnerability Assessment](./Hackazon%20Vulnerability%20Assessment/)** — Vulnerability scan and report against a deliberately vulnerable web app using Nmap, Nessus, and Nikto. Found 22 vulnerabilities (across host and application layers) and ranked the top 6 by severity, and gave remediation recommendations.
- **[Home Network VPN Deployment](./Home%20Network%20VPN%20Server/)** — Deployed a WireGuard VPN server on a home network, with firewall/NAT configuration and remote-access testing.
- - **[Metasploitable2 Vulnerability Discovery and Exploitation](./Metasploitable2%20Exploitation/)** — Discovered and exploited two known CVEs (vsftpd backdoor, DistCC RCE) on an isolated lab target using Nmap, OpenVAS, and Metasploit, from initial scan through to root shell.

More projects will be added here as I complete more coursework and independent labs.
